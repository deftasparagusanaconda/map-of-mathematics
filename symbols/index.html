∀ denotes that a statement holds for every element under consideration
∃ denotes that at least one element satisfying a statement exists
∈ denotes membership of an element in a set
∉ denotes that an element is not a member of a set
⊂ usually denotes a proper subset, though conventions vary
⊆ denotes a subset that may equal the containing set
∅ denotes the set containing no elements
ℕ usually denotes the natural numbers, with conventions differing over whether zero is included
ℤ denotes the set of integers
ℚ denotes the set of rational numbers
ℝ denotes the set of real numbers
ℂ denotes the set of complex numbers
⇒ denotes logical implication
⇔ denotes logical equivalence or if and only if
≅ often denotes an isomorphism or geometric congruence
≃ often denotes an equivalence whose precise meaning depends on context
≈ denotes approximate equality
≡ often denotes identity, congruence or definitional equality depending on context
∘ usually denotes function composition
⊗ usually denotes a tensor product or another monoidal product
⊕ usually denotes a direct sum or another additive operation
∑ denotes a sum indexed over specified values
∏ denotes a product indexed over specified values
∫ denotes integration over a domain
